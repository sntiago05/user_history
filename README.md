# Inventario con historial (Python)

Módulos en **Python** para gestionar un inventario de productos (id, nombre, precio y cantidad) con persistencia en archivo y manejo de excepciones propias.

## Módulos
- `inventory.py`: estructura y operaciones del inventario
- `service.py`: lógica de negocio (alta de productos, etc.)
- `handle_files.py`: lectura y escritura de archivos
- `exceptions.py`: excepciones personalizadas
- `diagram.png`: diagrama del diseño

## Estado
Aún no tiene un punto de entrada (`main.py`); los módulos se pueden importar y probar directamente.

## Proyecto de aprendizaje
Práctica de módulos, excepciones y manejo de archivos en Python.
